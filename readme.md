# Métodos utilizados

Para as primeiras experiências e finalização da réplica da obra utilizei o Web Editor do Pj5s e como referência ara as medidas dos quadrados e linhas usei a ferramenta de medição do Adobe Illustrator. Comecei por fazer os retângulos com a função rect e, sucessivamente, utilizei o mesmo método para as linhas pretas. Utilizei AI como auxílio na pesquisa de como adquirir os detalhes estéticos, tais como o _gradient_ de fundo e as pequenas pintas que imitam a textura da obra original de mondrian.
