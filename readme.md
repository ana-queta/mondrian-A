# Título

Neste projeto utilizei o Adobe Illustrator como referência para as medidas dos quadrados e linhas. Fiz os rectângulos com a função rect e, sucessivamente, utilizei o mesmo método para as linhas pretas. Utilizei AI como auxílio na pesquisa de como adquirir os detalhes estéticos, tais como o gradiente de fundo e as pequenas pintas que imitam a textura da obra original de mondrian.
